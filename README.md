# Clicca o salta?

Gioco educativo per ragazzi dagli 11 ai 18 anni: arriva un messaggio, un vocale o una chiamata, e bisogna decidere se è sicuro o se è una truffa. Ci sono tre difficoltà, scenari in cui conta il contesto e vocali da ascoltare.

Si gioca dal browser, senza installare nulla e senza registrarsi. Nessun dato viene raccolto.
